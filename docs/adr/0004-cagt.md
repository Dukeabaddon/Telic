# ADR-0004: Complexity-Adaptive Governance Topology (CAGT)

**Status:** Accepted (v0.1.2 preview)

## Context

ADR-0001 promised a direct single-agent path for simple requests. The v0.1.1 controller always walked the full nine-phase ceremony, including for short `report_only` prompts the README told users to handle without Telic.

## Decision

Introduce **RunTopology** with three values:

| Topology   | When                                                    | Phase graph                           |
| ---------- | ------------------------------------------------------- | ------------------------------------- |
| `micro`    | Short `report_only`, read-only, bounded                 | ground → frame → spot review → report |
| `standard` | Default / investigative / plan / fix                    | existing full FSM                     |
| `forensic` | Elevated capabilities, long requests, `analyze_and_fix` | full FSM (classification lock)        |

Classification is deterministic in `classifyRun()` at `startRun`. The controller may inject `TaskContract` + `WorkPlan` during micro bootstrap after `ProblemFrame`.

## Consequences

### Positive

- Short report-only runs skip compile, prompt review, plan, execute (when mode requires), and release audit.
- `run.topology` and envelope `topology` are inspectable.
- `topology_override` MCP input supports explicit host control.

### Negative / deferred

- Micro does not yet cover short `fix_only` typo paths (still `standard` / `forensic`).
- Forensic and standard share the same FSM today; forensic is a classification lock only.

Evidence-gated escalation foundation is documented in [ADR-0005](./0005-egel.md).

- `state-machine.test.ts` — micro routing
