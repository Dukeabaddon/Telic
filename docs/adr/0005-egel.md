# ADR-0005: Evidence-Gated Escalation Ladder (EGEL) — foundation

**Status:** Accepted (Loop 1 foundation)

## Context

CAGT v1 (`ADR-0004`) introduced `micro` topology but treated spot-review `partial` and `remediate` as terminal blocked paths. That wasted the governance graph instead of promoting work when micro evidence was insufficient.

## Decision

1. **Micro spot-check failures promote to `standard`.**
   - `QualityReview.decision === "partial"` → `topology: standard`, phase `agent_1_review`.
   - `QualityReview.decision === "remediate"` → same promotion (Loop 1 uses `partial` in tests; remediate follows identical ladder).
   - `block` and `pass` remain on the micro graph.

2. **Trace-only escalation records.**
   - Emit `topology_escalated` with reason codes `MICRO_SPOT_PARTIAL` / `MICRO_SPOT_REMEDIATE`.
   - No new artifact type in Loop 1.

3. **Ledger persists live topology.**
   - `runs.topology` updates on every `applySubmission` / `transitionWithoutArtifact`.

4. **Micro `UserReport` uses full evidence semantics.**
   - `assertEvidenceSemantics` runs before micro early return.

## Consequences

### Positive

- Micro stays fast when spot-check passes.
- Insufficient evidence automatically unlocks standard contract review.
- Escalation is auditable via trace.

### Deferred (Loop 2+)

- Escalation from evidence kind mismatch before review.
- `RunEnvelope.topology` live update vs start-time snapshot.
- Micro `fix_only` path.
- Forensic-only re-verify phases.
